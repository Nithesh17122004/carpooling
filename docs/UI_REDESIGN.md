# RideMate UI redesign

Visual direction: premium mobility with deep teal, sea-glass mint, warm white and graphite. Keep the existing vanilla-JS SPA and API contracts to avoid replacing stable business logic.

Desktop: 260px navigation rail and wider canvas. Tablet: compact sticky top bar and stacked details. Mobile: sticky top bar, safe-area-aware bottom navigation, single-column forms/cards, full-width bottom sheets, and 44px+ tap targets.

Native select controls are retained for keyboard and assistive-technology behavior. Use readable option colours and responsive widths. Autocomplete panels must layer above maps/cards and remain touch-scrollable.

The RideMate wordmark remains. A new road/car hybrid SVG mark is used in the app shell and auth views. The existing app icon asset is retained until the full PNG/PWA icon set is regenerated.
